# Бот-агент: аналитика рекламы + специалист по Директу

Telegram-бот на базе LLM-агента. Понимает вопросы на естественном языке,
сам выбирает нужные инструменты, тянет данные и формулирует выводы.

Две роли в одном агенте:
- **Аналитик кампаний** — метрики, динамика период-к-периоду, аномалии, рекомендации.
- **Специалист по Директу** — расширение семантики, минус-слова, написание и проверка объявлений.

> Сейчас данные **мок** (генерируются на лету), чтобы бот запускался без доступов к API.
> Реальная интеграция с Яндекс.Директом — отдельный шаг (см. «Дорожную карту»).

## Запуск за 4 шага

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Создайте бота в Telegram через [@BotFather](https://t.me/BotFather), получите токен.
3. Скопируйте `.env.example` в `.env` и заполните `TELEGRAM_TOKEN` и `ANTHROPIC_API_KEY`.
4. Запустите:
   ```bash
   python bot.py
   ```

Напишите боту `/start`, затем, например: «Что с CPA в clinic-stoma за неделю?»

## Структура

| Файл | Назначение |
|------|-----------|
| `bot.py` | Telegram-интерфейс (aiogram), память диалога |
| `agent.py` | Цикл tool-use: LLM сама вызывает инструменты |
| `tools.py` | Инструменты: аналитика + Директ (схемы + функции) |
| `data.py` | Источник данных: мок-провайдер + заглушка клиента Директа |
| `config.py` | Настройки из `.env` |

## Как это работает

Пользователь пишет вопрос → агент (`agent.py`) отправляет его модели вместе со
списком инструментов → модель решает, что вызвать (например `get_metrics` или
`compare_periods`) → `tools.py` выполняет функцию на данных из `data.py` →
результат возвращается модели → она формулирует ответ. Цикл повторяется, пока
модель не перестанет запрашивать инструменты.

**Почему один агент, а не два бота.** Вы хотели аналитика и специалиста по
Директу. Архитектурно это просто два набора инструментов у одного агента —
проще поддерживать и удобнее вам (всё в одном чате). Захотите разделить —
отдавайте агенту разные подмножества `TOOL_SCHEMAS`, и из одного кода получите
два бота.

## Дорожная карта

1. **Сейчас (готово):** агент, оба набора инструментов, бот, мок-данные.
2. **Реальный Директ:** реализовать `YandexDirectClient` в `data.py` через
   Reports API; переключить `get_provider()`. Доступ к API запросить заранее —
   это обычно дольше всего.
3. **Хранение и расписание:** SQLite + регулярная синхронизация метрик
   (APScheduler), чтобы не дёргать API на каждый вопрос.
4. **Проактивность:** ежедневные алерты по аномалиям (расход вырос на X%,
   просадка конверсий) — бот пишет сам, без вопроса.
5. **Графики:** `build_chart` через matplotlib → PNG в чат.
6. **Семантика по-взрослому:** Wordstat API для реальной частотности ключей.
