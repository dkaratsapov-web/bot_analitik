## Приоритет 2 — хранение и расписание

- [x] SQLite-хранилище метрик + регулярная синхронизация (APScheduler),
  чтобы не дёргать API на каждый вопрос. Слой данных не тянет тяжёлых
  зависимостей: `storage.py` — только стандартный `sqlite3`, APScheduler
  подключён лишь в `bot.py`.
  - `storage.py` — таблицы `metrics` / `sync_meta`, upsert и чтение «сырых» строк.
  - `data.CachedProvider` — обёртка над любым провайдером поверх SQLite,
    с ленивой досинхронизацией при промахе кэша.
  - Включается через `USE_CACHE=true` в `.env` (по умолчанию выключено —
    мок-фолбэк сохранён). Бот синхронизирует кэш по расписанию
    (`SYNC_INTERVAL_MINUTES`).
  - Round-trip кэша покрыт в `smoke_test.py` (без сети).
